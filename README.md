# ☕ Brewé — Coffee Shop Website

Welcome to Brewé, a coffee shop website where customers can explore coffee options, add items to their cart, and place orders.

## ✨ Features

- 🏠 Home page
- ☕ Coffee menu with prices
- 🛒 Shopping cart with quantity and total calculation
- 🧾 Checkout page with customer details
- 📩 Contact form
- 🔐 Admin panel to view orders and customer details

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- SQLite

## 📁 Project Structure

- `index.html` — Home page
- `menu2.html` — Coffee menu and cart
- `about.html` — About page
- `contact.html` — Contact page
- `checkout.html` — Checkout page
- `admin.html` — Admin orders panel
- `backend/app.py` — Flask backend
- `backend/brewe.db` — SQLite database

## ▶️ Run Locally

1. Install Python.
2. Install the required packages:

   ```bash
   pip install flask flask-cors
   ```

3. Open a terminal in the `backend` folder.
4. Run the backend:

   ```bash
   python app.py
   ```

5. Open the frontend using a local development server.
